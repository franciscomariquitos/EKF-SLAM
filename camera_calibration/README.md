# Camera calibration

This folder contains the camera calibration files used for the TurtleBot3 EKF-SLAM experiments with ArUco landmarks.

## Files

- `ost.yaml`: camera calibration file generated by the ROS camera calibration tool.
- `ost.txt`: calibration summary exported by the calibration tool.
- `my_cam_monocular.yaml` optional: formatted calibration file used by the camera node, if included.

## Calibration procedure

The camera was calibrated using the ROS monocular camera calibration tool and a checkerboard calibration target.

Example command:

```bash
ros2 run camera_calibration cameracalibrator \
  --size 8x6 \
  --square 0.025 \
  --ros-args \
  -r image:=/image_raw \
  -r camera:=/camera
